# Пересборка ролика

Проект по умолчанию — тот, о котором шла речь в разговоре. Если непонятно какой,
спроси одной строкой, а не угадывай.

## Порядок

1. **Свериться с реальностью.** Прочитать `сценарий\монтаж.md` (или `монтаж.md` в корне)
   и посмотреть, что реально лежит в `видео\` и в корне. Часто файл из листа уже удалён,
   а рядом лежит новая генерация с другим именем — это и есть замена.

   ```bash
   ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate \
     -show_entries format=duration -of default=nw=1 "<файл>"
   ```

2. **Подобрать окно** для новых или заменённых фрагментов — через скилл `frame`.
   Не ставить `с 0` по умолчанию: первые кадры генерации ещё «собираются».

3. **Обновить монтажный лист.** Поправить строку таблицы и пояснения под таблицей —
   в этих проектах текст под таблицей объясняет, почему длительности именно такие,
   и устаревать ему нельзя. Держать общую длину: если под ролик записана озвучка,
   сумма длительностей обязана совпадать с её длиной, иначе голос разъедется с картинкой.

4. **Dry-run.**

   ```powershell
   .\run.ps1 "<проект>" -DryRun
   ```

   Проверить: все фрагменты нашлись, «Итого» совпадает с ожидаемым, нет предупреждений
   про длину строки текста и про нехватку секунд после сдвига.

5. **Отложить прежний рендер** — сборка перезаписывает `финал\ролик.mp4` молча.

   ```powershell
   Move-Item "<проект>\финал\ролик.mp4" "<проект>\финал\ролик_<что-было>.mp4" -Force
   ```

6. **Собрать.**

   ```powershell
   .\run.ps1 "<проект>"
   ```

7. **Проверить результат кадром** — вырезать кадр из изменённого места и посмотреть
   его глазами (текст на экране, кадрирование, тот ли фрагмент):

   ```bash
   ffmpeg -y -v error -ss <сек> -i "<проект>/финал/ролик.mp4" -frames:v 1 -vf scale=720:-1 check.jpg
   ```

   Временные кадры класть в scratchpad, не в папку проекта.

## Отчёт

Две-четыре строки: что изменилось в листе, какое окно взято и почему, длина ролика,
куда отложен старый рендер. Без пересказа шагов.
