# Новый проект ролика

Название: `$ARGUMENTS`. Если пусто — спросить одной строкой.

## Скелет

Создать `пример\<название>\` (боевые проекты живут там же, где учебные):

```
<название>\
  видео\                      ← генерации
  сценарий\
    монтаж.md
    промты.md
    озвучка.md
  финал\
```

## Монтажный лист — заготовка

```markdown
# Монтажный лист — «<название>»

| № | Файл | Длительность | Текст на экране | Примечание |
|---|------|--------------|-----------------|------------|
| 1 |  |  |  |  |

- **Формат:** горизонталь
- **Музыка:**
- **Озвучка:**
```

**Формат ставить по формату генераций**, а не по площадке: 16:9-исходник в вертикали
теряет две трети ширины и срезает героя.

Строки `**Музыка:**` / `**Озвучка:**` ищутся по всему файлу — не писать их в пояснениях
«для примера», они сразу рабочие. Пустое значение = дорожки нет.

## Что заполнить

- **промты.md** — по одному промту на фрагмент. Промты для генераций писать без
  фото-языка (`film grain`, `realism`, `macro lens`) — он утаскивает картинку
  в фотореализм даже при иллюстративных референсах.
- **озвучка.md** — таблица «№ | Кадр | Реплика», реплики по 7–9 слов.
- Под таблицей монтажного листа — короткое пояснение, почему длительности такие:
  в этих проектах оно живое и его читают.

## Дальше

Драматургия минимум в четыре такта: завязка → беда → поступок → мораль. Когда файлы
принесены — окна подбирать скиллом `frame`, сборка — скиллом `assemble`.
