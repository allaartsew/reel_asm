# Выбор окна внутри генерации

Генерации приходят по 5–15 секунд, в монтаж идут лучшие 3–6. Начало почти всегда
плохое: первые кадры ещё «собираются». Хвост тоже проверять — он часто плывёт.

## Порядок

1. Длительность и размер:

   ```bash
   ffprobe -v error -select_streams v:0 -show_entries stream=width,height \
     -show_entries format=duration -of default=nw=1 "<файл>"
   ```

2. Нарезать превью в scratchpad (не в папку проекта) — шаг ~2 секунды плюс последний кадр:

   ```bash
   for t in 0 2 4 6 8; do
     ffmpeg -y -v error -ss $t -i "<файл>" -frames:v 1 -vf scale=640:-1 "f_$t.jpg"
   done
   ffmpeg -y -v error -sseof -0.15 -i "<файл>" -frames:v 1 -vf scale=640:-1 "f_end.jpg"
   ```

3. **Посмотреть кадры глазами** (прочитать jpg как изображения). Оценить:
   - куда идёт камера — наезд или отъезд;
   - где герой в кадре: при центральной обрезке под формат ролика края уедут;
   - не поплыло ли изображение к концу;
   - хватит ли места снизу под текст на экране (он прижат к низу, ~12% высоты).

4. Предложить строку для монтажного листа: `<длительность> с <старт>` — и одной фразой
   почему именно это окно. Если под ролик уже записана озвучка, длительность фиксирована
   слотом, двигать можно только старт.

## Правило хвоста

Если камера весь клип отъезжает, брать хвост — ролик закончится на самом широком плане.
Если наезжает — наоборот, и финал придёт на крупный.
